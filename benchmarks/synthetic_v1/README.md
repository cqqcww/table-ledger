# 版式与数值集

36 份原创合成文档、216 题：提取 108 题（50.00%）、推理 72 题（33.33%）、局部结构恢复 36 题（16.67%）。原件为 33 张 PNG 与 3 份双页 PDF，每份文档对应六道题。

12 个模板族各有三个固定种子变体，覆盖合并表头、列换序、千分位、括号负数、前导零编号、真实空白、单位倍率、弱边框、低清、旋转、干扰脚注和跨页重复表头。模板族名称用于组织版式，不代表真实来源行业的分布。

历史划分为 8 族 / 24 文档 / 144 题 `dev`，4 族 / 12 文档 / 72 题 `holdout`。当前两部分均已用于开发或回归，不再作为本项目的新未见集。题目、标准答案和源表完整保留在 [benchmark.json](benchmark.json)；原件在 [files/](files/)。

生成源码：[layouts.py](../generators/layouts.py)。基准随机种子为 `84673`；源表已按显示列顺序排列，合并关系使用零起始坐标。标准答案由渲染前的单元格与精确十进制运算得到。

使用、字段、许可与重建方式见 [数据总说明](../README.md)。
