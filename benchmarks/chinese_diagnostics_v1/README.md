# 部门与范围集

12 份原创合成 PNG 文档、60 题：提取 36 题（60.00%）、推理 24 题（40.00%），每份文档对应五道题，没有结构恢复题。

覆盖部门跨行合并、重复“金额”叶表头、按题目顺序提取、空白/零/横杠、括号负数、元与万元、小计/合计排除、干扰脚注、列重排、小图和旋转。所有文档共享同一生成器与问题族，主要用于范围、单位和独立重读的回归诊断。

历史 `split` 字段均为 `holdout`。这些数据现在已被观察并用于迭代，当前按回归集使用。题目、标准答案与源表完整保留在 [benchmark.json](benchmark.json)，原件在 [files/](files/)。

生成源码：[departments.py](../generators/departments.py)，每份文档的种子为 `730031` 至 `730042`。`source.rows` 是逻辑列顺序，渲染图像的列顺序由 `source.column_order` 指定；核对坐标时必须先应用排列。

使用、字段、许可与重建方式见 [数据总说明](../README.md)。
