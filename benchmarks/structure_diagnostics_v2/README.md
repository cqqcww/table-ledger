# 结构与范围诊断

40份原创文档、160题：每份文档有完整列数、完整行数、表头层数三道计数题，以及一道局部结构恢复题。合计120道 `extract`、40道 `structure`，包含34张PNG与6份双页PDF。

结构题要求前1或2行与首列的并集，保留完整表格行列数及真实合并跨度，跨页重复表头映射回原逻辑行。计数和结构答案都来自渲染前的源格，没有使用预测作为真值。

按源文档统一分为6份训练（24题）、10份开发（40题）和24份确认（96题）。截至2026-11-05，两份训练文档已作视觉示例，10道开发结构题已评测；计数题尚未单独评测，但不能因此忽略同文档的训练或开发暴露。确认文档尚未推理。各题 `usage_status` 记录具体情况。

与版式计数集共享生成器家族；数值仅供排版，不用于计算任务。详见[全集说明](../README.md)。原件、标注和生成代码采用 AGPL-3.0-only，可用 `generators/geometry.py --suite structure` 重建。
