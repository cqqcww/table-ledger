# 版式计数诊断

24份原创文档、72题：完整列数、完整行数和表头层数各24题，均标记为 `extract`，答案为整数。包含20张PNG与4份双页PDF。

维度、层级表头、纵向合并、弱边框、旋转和跨页会变化；重复表头只计一次，合并格覆盖的底层行列分别计数。源格、页到逻辑行映射与原件摘要完整保留。

历史54题开发与18题确认均已使用，目前用于回归。它与新增结构集共享生成器，不能据此声称模板隔离或真实文档泛化。详见[全集说明](../README.md)。

原件和生成代码采用 AGPL-3.0-only。使用 `generators/geometry.py --suite layout` 可在自备字体条件下重建到新目录。
